# FIT VLAD

This repository contains the technical handoff and design assets for a private workout PWA.

Start with [the technical handoff](docs/TECHNICAL_HANDOFF.md). Use [the agent task](docs/AGENT_TASK.md) to continue implementation.

The selected stack is TanStack Start, React, TypeScript, shadcn/ui, Tailwind CSS, Recharts, Prisma, Better Auth, and Cloudflare Workers. Develop against local D1 SQLite. Create remote D1 when ready to deploy.

The main design reference is [the supplied mockup](assets/reference/approved-design-reference.png). Read [the asset guide](assets/README.md) before using generated exercise art.

No application code or cloud resources have been created by this handoff.
